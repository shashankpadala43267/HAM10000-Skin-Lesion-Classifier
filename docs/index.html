Overview

Project Overview

This project applies EfficientNetB0 transfer learning to dermoscopic images from the HAM10000 dataset. The model predicts seven skin-lesion categories.

The workflow includes metadata exploration, image-path mapping, lesion-grouped dataset splitting, TensorFlow data pipelines, image augmentation, class balancing, two-stage training, evaluation, and high-confidence error analysis.

Research focus: Building and evaluating an imbalanced medical-image classifier while preventing lesion-level data leakage.

Data

Dataset Split

Images were divided into training, validation, and testing groups using lesion IDs to prevent the same lesion from appearing in multiple splits.

7,002 Training images
1,519 Validation images
1,494 Testing images

Limitations

Important Limitations

  • The HAM10000 dataset is highly imbalanced.
  • Performance varies substantially among lesion classes.
  • The model produced high-confidence incorrect predictions.
  • Results may not generalize beyond HAM10000.
  • The model does not use clinical history or patient context.
  • The model has not undergone clinical validation.
