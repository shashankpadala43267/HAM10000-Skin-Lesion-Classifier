HAM10000 Skin Lesion Image Classifier

An educational deep-learning project exploring EfficientNetB0, lesion-level dataset splitting, class imbalance, model evaluation, and high-confidence error analysis.

View GitHub Repository View Results

Overview

Project Overview

This project applies EfficientNetB0 transfer learning to dermoscopic images from the HAM10000 dataset. The model predicts seven skin-lesion categories.

The complete workflow includes metadata exploration, image-path mapping, lesion-level dataset splitting, TensorFlow data pipelines, image augmentation, class balancing, training, evaluation, confusion-matrix analysis, and examination of high-confidence mistakes.

Limitations

Important Limitations

  • The HAM10000 dataset is highly imbalanced.
  • Performance varies substantially among lesion classes.
  • The model produced high-confidence incorrect predictions.
  • Results may not generalize beyond HAM10000.
  • The model does not use patient history or clinical context.
  • The model has not been clinically validated.

Safety

Educational Disclaimer

This project is an educational machine-learning experiment. It does not provide medical advice, diagnosis, screening, treatment recommendations, or emergency guidance.
